公共在线报表接口

第三方系统（MES/ERP 等）完整接入说明见 🔌集成指南。

公共接口支持两种鉴权：平台登录会话（Cookie）或 API Token（X-API-Token 头或 ?token= 参数，见 config.yaml 的 auth.api_tokens）。限流：公共接口默认 20次/秒/IP。所有响应统一为 {success, message, code, result, timestamp}， success=true 时业务数据在 result 中。

GET/online/cgreport/api/getData/{code} 查询报表数据（分页 + 条件 + 排序 + 参数）
参数位置必填说明
code路径是报表编码（如 demo_report）
pageNo / pageSizequery否页码(默认1) / 每页条数(默认10，最大100000)
needCountquery否传 false 跳过 COUNT 查询（total/pages 返回 -1），适合导出、大报表；分页场景服务端已带 10s COUNT 缓存
needSummaryquery否传 true 返回合计列汇总（result.summary），对配置了“合计列”的数值字段在过滤后的全量结果集上求 SUM
column / orderquery否排序列(须为已配置字段) / asc、desc；COUNT 查询已剥离排序开销
{查询字段}query否报表字段配置了“查询”的条件值，按查询模式(=/like/in/between...)过滤；between 用 字段_begin / 字段_end
列上筛选query否任意已配置列可筛选：列=值 精确、列_like 模糊、列_in=a,b 枚举、列_bw=a,b 区间、列_ne/_gt/_ge/_lt/_le 比较，与查询区条件叠加
{报表参数}query否SQL 中 ${name} 参数的值，未传时使用参数默认值

GET/online/cgreport/api/getColumns/{code} 查询报表字段配置（渲染报表用）
result: { head: {...}, fields: [ { fieldName, fieldTxt, fieldType, isShow, isQuery, queryMode, ... } ], params: [ { paramName, paramTxt, paramValue } ], columns: [...] }
GET/online/cgreport/api/getInfo/{code或id} 查询报表完整配置（头 + 字段 + 参数）
POST/online/cgreport/api/saveData/{code} 公共保存：新增 / 修改报表对应数据表的数据

保存目标表 = 报表SQL 解析出的主表（也可用 table 显式指定）。 data.id 有值且存在 → UPDATE；否则 INSERT（id 自动生成）。字段名必须是合法表字段。

POST /online/cgreport/api/saveData/demo_report
Content-Type: application/json

{
  "data": { "id": "", "name": "新用户", "sex": "男", "age": 25, "salary_money": 888.88 }
}

// 批量保存
{ "dataList": [ {...}, {...} ] }

// 响应
{ "success": true, "result": { "saved": 1, "ids": ["3f2a..."] } }
POST/online/cgreport/api/importExcel/{code} 导入 Excel：按表头批量写回报表主表

multipart/form-data，文件字段名 file（.xlsx，≤5MB）。 首行为表头，按报表字段名匹配（大小写不敏感，未知列忽略）；数据行批量写回（事务，任一行失败整体回滚）。 行内 id 有值且存在则更新，否则新增。

curl -X POST -H "X-API-Token: demo-token-123"   -F "file=@数据.xlsx"   http://localhost:8085/online/cgreport/api/importExcel/demo_report

// 响应 result: { "imported": 100 }
