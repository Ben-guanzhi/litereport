第三方系统集成指南（MES / ERP / WMS 等）

LiteReport 为第三方系统提供两种对接通道：公共 API（数据查询/写入/导出/聚合，Token 鉴权）与页面嵌入（报表页 iframe）。 所有公共接口统一响应 {success, message, code, result, timestamp}，success=true 时业务数据在 result。

STEP0. 前置准备（一次性）
事项说明
网络MES 服务器能访问 LiteReport 端口（默认 8085，可经网关反代）
令牌在 LiteReport 服务器 config.yaml → auth.api_tokens 为 MES 分配专用 Token（建议独立、定期轮换），改后重启
数据来源（推荐）直连模式：数据源管理页面把数据源指向 MES 数据库（只读账号），报表 SQL 直接查 MES 的工单/报工/质检表，数据零同步、实时
数据来源（可选）落库模式：表单开发向导建表，MES 通过公共保存接口反写数据
模式一MES 后端拉数据推荐：Token 只保存在 MES 服务端

MES 服务端持有 Token 调公共接口，MES 前端自行渲染。表格用 getColumns+getData，图表用 getChartData，交叉分析用 getCrossTable。

// Java 示例 —— 查询"当日报工"第1页（区间筛选 + 精确筛选 + 合计）
HttpGet get = new HttpGet("http://litereport:8085/online/cgreport/api/getData"
    + "/bao_gong?pageNo=1&pageSize=50"
    + "&create_time_bw=2026-09-01 00:00:00,2026-09-06 23:59:59"   // 列上筛选：介于
    + "&line_no=SMT-01"                                           // 列上筛选：精确
    + "&needSummary=true");                                       // 返回合计
get.setHeader("X-API-Token", "mes-token-xxx");
// result.records = 数据行  result.total = 总数  result.summary = 合计列汇总
// result.records 内字典字段已可在渲染端用 getDict 翻译
// 列上筛选速查（列名必须在报表字段配置中）
列=值              精确         列_like=值        模糊
列_in=a,b          枚举         列_bw=a,b         区间
列_ne / _gt / _ge / _lt / _le    比较
// 排序与分页：column=列名 & order=asc|desc & pageNo & pageSize
// 跳过计数（大数据量）：needCount=false → total 返回 -1
// curl 自测（先在平台内确认报表编码，如 demo_report）
curl -H "X-API-Token: mes-token-xxx" \
  "http://litereport:8085/online/cgreport/api/getData/demo_report?pageNo=1&pageSize=10&name=王"
模式二iframe 嵌入报表页面

在报表配置列表 → 更多 → 配置地址，复制页面地址（/online/cgreport/{id}）嵌入 MES：

<iframe src="http://litereport:8085/online/cgreport/{id}"
        style="width:100%;height:800px;border:0"></iframe>

页面走登录会话。跨域 iframe 时 Cookie 受限，两种解法：① LiteReport 与 MES 同主域（如 mes.company.com / report.company.com）且启用 HTTPS；② 改用模式一由 MES 自渲染（推荐）。

模式三MES 反写数据（公共保存/删除）

把采集/上报数据写进 LiteReport 管理的数据表（表可由「Online表单开发」向导创建，自动生成对应报表）。data.id 有值且存在则更新，否则插入（id 自动生成）。

# 单条上报
curl -X POST -H "X-API-Token: mes-token-xxx" \
  -H "Content-Type: application/json" \
  http://litereport:8085/online/cgreport/api/saveData/mes_collect \
  -d '{"data":{"sn":"PCB20260906001","line_no":"SMT-01","qty":120,"result":"OK"}}'

# 批量（含修改：id 有值走 UPDATE）
-d '{"dataList":[{"id":"abc123","qty":130},{"sn":"PCB002","qty":50,"result":"NG"}]}'

# 删除误录
curl -X POST -H "X-API-Token: mes-token-xxx" \
  http://litereport:8085/online/cgreport/api/deleteData/mes_collect \
  -d '{"ids":["abc123"]}'
模式四报表主动推送
  • 定时推送：推送页面（📤推送）配置任务，按分钟间隔把报表 Excel 作为附件发邮箱（smtp 段配置）
  • 钉钉/企微群机器人：渠道选“钉钉机器人/企微机器人”，填群机器人 webhook，产线日报定时推卡片到群
  • MES 侧也可自拉：定时调 exportExcel/{code} 落文件
TIPS安全与运维建议
#建议
1Token 只放 MES 服务端，不要下发到浏览器代码；浏览器直调场景经 MES 网关转发
2直连模式使用只读数据库账号；仅反写场景为对应表单独开写权限
3MES 高频轮询时调大 ratelimit.public_rps；多实例部署配置 ratelimit.redis_addr 共享限流窗口
4状态码类字段在「字典管理」配好，报表与查询区自动翻译
5公共接口路径与响应结构保持稳定；MES 侧以 success 字段判断成败，限流时返回 429
API公共接口速查（完整参数见 公共接口文档）
接口用途
GET /online/cgreport/api/getData/{code}分页查询（筛选/排序/参数/汇总）
GET /online/cgreport/api/getDataNoPage/{code}全量查询（跳过计数）
GET /online/cgreport/api/getColumns/{code}字段配置（动态渲染表格）
GET /online/cgreport/api/getInfo/{code或id}报表完整配置
GET /online/cgreport/api/getChartData/{code}维度聚合（图表）
GET /online/cgreport/api/getCrossTable/{code}交叉表
GET /online/cgreport/api/getDict/{code}字典项
GET /online/cgreport/api/exportExcel/{code}导出 Excel（带条件）
POST /online/cgreport/api/saveData/{code}保存（插入/更新/批量）
POST /online/cgreport/api/importExcel/{code}导入 Excel（multipart file，首行表头=字段名）
POST /online/cgreport/api/deleteData/{code}删除
