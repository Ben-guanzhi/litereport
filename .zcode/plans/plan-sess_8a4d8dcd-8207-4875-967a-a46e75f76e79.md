## LiteReport 第四批优化计划(收尾批次)

前三批已修复功能 Bug、安全加固、推送可观测性、事务化与保留策略。本批处理分析报告中剩余的中低优先级项,以「安全收尾 + 前端健壮性 + 测试补充」为主。

### 一、HTTP 层收尾
1. **OPTIONS 预检不再被 401 拦截**(`internal/api/server.go`):在中间件链最外层(authMiddleware 之前)短路 OPTIONS 请求,直接返回 204,跨域第三方预检可正常通过。
2. **CORS 收敛**:根 handler 中 `Access-Control-Allow-Origin: *` 仅对公共接口 `/online/cgreport/api/` 下发;管理端 `/api/*` 不再下发通配跨源头(同源使用,无需要)。
3. **交叉表行数上限**(`internal/service/extra2.go` CrossTableData):聚合结果用 `dbx.LimitWrapN` 限制最多 5000 行,`CrossTable` 结构加 `truncated` 字段提示前端;防止高基数维度把百万行拉进内存。

### 二、用户管理安全
4. **config 用户保护**(`internal/api/extra.go` handleUserSave):用户名存在于 `auth.ConfigUsers()`(config.yaml 定义)时拒绝在页面新增/修改同名 DB 用户,避免遮蔽 config 用户。
5. **防自删与保底 admin**(handleUserDelete):拒绝删除当前登录用户自己;删除后校验平台仍至少有 1 个 admin(DB + config 合计),否则拒绝。

### 三、前端健壮性
6. **ai.html**:`var history` 改名 `chatHistory`,不再遮蔽浏览器原生 `window.history`。
7. **common.js `api()`**:响应处理增加 `res.ok` 与 Content-Type 判断——网关 502/HTML 响应时报「服务异常(HTTP xxx)」而非 `Unexpected token`;JSON 解析失败给出可读错误。
8. **补 .catch**:push.html 的 `del`、dict.html/chart.html/datasources.html 的删除与加载调用补上失败提示,不再静默失败。
9. **onclick 单引号注入**(`users.html`、`dict.html` 编辑按钮):用户名含 `'` 时破坏 JS 字符串。改为 `data-name` 属性 + 事件委托,不再把数据拼进行内 JS。
10. **login.html**:移除「默认账号 admin / admin123」提示(生产环境不应展示)。

### 四、死代码与文档
11. **`report.go` cachedSummary**:删除永不超过的第二次 `if len(list)==0` 判断。
12. **README**:「已知约束」补充两条——交叉表聚合最多返回 5000 行;API Token 的 `?token=` 方式会进入浏览器历史/网关日志,生产建议统一用 `X-API-Token` 请求头。

### 五、测试
13. **交叉表截断测试**:service 层用内存 sqlite 验证超限截断与 truncated 标记。
14. **config 包测试**(当前零覆盖):默认值、normalize(角色归一、local 数据源补全、保留天数默认)。
15. **用户管理测试**:viewer 删自己被拒、删最后一个 admin 被拒、config 用户被拒(挂到 api 层或 e2e)。

### 验证
`go build`、`go vet`、`go test ./...` 全绿;服务重启后用浏览器实测:登录页无默认账号提示、用户管理删除保护、交叉表大维度场景正常。

### 不做(明确排除)
- token 完全弃用 query 形式(兼容存量第三方,仅文档提示)
- cgreport 分组汇总按 name 对齐(列错位为多度量聚合的既有设计限制,改动面大)
- workspace.html 硬编码的接口数量文案
- 推送连续失败退避(已有状态可见 + 周期重试,够用)
